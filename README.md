## How to edit the deck (in your browser, no code)

The deck has a built-in editor. To change any wording:

1. Open the deck in your browser (the live URL above, or `afrotech-ai-edge-session-02-people-leaders.html` locally).
2. Click **Edit Mode** in the top-right toolbar.
3. Click any text on any slide to edit it. Edits auto-save to your browser as you go.
4. When you're done, click **Download HTML** to get the updated file.
5. Replace the file in this repo with your downloaded version (or send it back to Brandon and he'll commit it).

> **Reset** clears your local edits and reloads the original. Use it if you want to start over.
